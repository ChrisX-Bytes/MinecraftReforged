## 两个问题的根因（终于定位准确）

### 问题 1（渲染：流水是二维蓝色正方形，能透过水看到后面的方块）
**根因（水-水相邻面无差别剔除）**：buildMesh 邻居判断把**所有**水-水相邻面都剔除，包括**不同水位之间**的共享面。当高水位水（满）旁是低水位水（顶面低）时，共享面被剔除 → 高水位水暴露出的那部分侧面（低水位顶面以上的垂直部分）**没有渲染** → 形成一个缺口 → 透过缺口能看到后面的方块。

**修复**：水-水相邻的剔除改为**仅当两方块水位完全相同时才剔除**。水位不同时不剔除——高水位方块朝低水位那面会画出暴露部分（台阶/瀑布侧面），消除"透视"缺口。

### 问题 2（流动：柱子顶端放水，水流下后流很远）
**根因（下落水柱每层都水平扩散）**：processSource 第 199 行 `spreadLevel = (myLevel==8)?1:myLevel+1`，让 level 8（下落柱）的**每一层**都向四周水平扩散 level 1。一根 10 格高的下落柱 = 10 个扩散源 → 在地面形成超大范围。

**MC 正确规则**：下落水柱(level 8)在**自由下落中**（下方空气/水）只继续向下，不水平扩散；只有**落地点**（下方是固体）才按 level 1 水平扩散。

**修复**：level 8 方块只在 `below` 是固体时才水平扩散；below 是空气/水时不扩散（只下落）。

## 修复方案（C++ 改动，需重新编译）

### 改动 1（修问题1）：subchunk.cpp 水面剔除改为按水位区分
buildMesh 邻居判断逻辑改为：
```cpp
// 当前是水时：邻居是水且水位相同 → 剔除；邻居是水但水位不同 → 不剔除（保留暴露面）
bool neighbor_occludes;
if (neighbor != BLOCK_AIR && neighbor != BLOCK_WATER) {
    neighbor_occludes = true;  // 固体遮挡
} else if (neighbor == BLOCK_WATER) {
    // 水-水：仅当水位相同时剔除
    uint8_t myWl = waterLevels[(ly*16+lz)*16+lx];
    uint8_t nWl = waterLevels[(ny*16+nz)*16+nx];
    neighbor_occludes = (myWl == nWl);
} else {
    neighbor_occludes = false; // 空气
}
```

### 改动 2（修问题2）：fluid_simulator.cpp level 8 仅落地点扩散
processSource 第 4 步（水平扩散）前加判断：
```cpp
// 下落水柱(level 8)只在落地点（below固体）水平扩散；下落中（below空气/水）只下落
if (myLevel == 8 && below != BLOCK_AIR && /* below 不是水 */) {
    // 落地，按 level 1 扩散
} else if (myLevel == 8) {
    return; // 下落中，不水平扩散
}
```
简化：level 8 且 below 是空气或水 → return（不扩散）；level 8 且 below 是固体 → 扩散 level 1。

## 防回归自检
- **海洋**：水源-水源水位相同(0=0) → 剔除内部面 → 海面平整不变。✓
- **水源旁流水**：水位不同(0 vs k) → 不剔除 → 暴露面渲染 → 台阶可见。✓
- **下落柱**：每层只下落不扩散 → 地面只在落地点扩散 → 范围正常(7格)。✓
- **平地水源扩散**：level 0-7 不变（水源本身 level 0，扩散正常）。✓
- **水可挖**：不受影响。✓
